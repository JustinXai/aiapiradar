- **Repository**: https://github.com/JustinXai/aiapiradar

## Architecture

| Layer | Technology |
|-------|------------|
| Framework | Astro (static site generator) |
| Data | `src/data/pages.ts` — centralized page factory |
| Pages | `src/pages/[...slug].astro` — dynamic routes from pages.ts |
| Homepage | `src/pages/index.astro` — hardcoded |
| 404 | `src/pages/404.astro` — custom 404 with noindex |
| SEO | `src/components/SeoHead.astro` |
| Layout | `src/components/Layout.astro` |
| Navigation | `src/data/navigation.ts` |
| Sitemap | `public/sitemap.xml` — generated by `scripts/generate-sitemap.mjs` |
| LLMs | `public/llms.txt` — generated by `scripts/generate-llms.mjs` |
| Robots | `public/robots.txt` |
| Validation | `scripts/validate-content.mjs` |
| Deployment | Cloudflare Pages (auto-deploys on push to main) |
